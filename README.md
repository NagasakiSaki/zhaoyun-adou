# 赵云与阿斗 · HTML 同款

一款纯前端实现的三国题材**汉字水墨·路径塔防**小游戏，玩法对齐抖音爆款《赵云与阿斗》（并参考同类型《悟空与唐僧》的地图与战斗模型）：8×10 镜像战场、S 形土路、守将红心、整手征兵、同字合成、武将拼字觉醒。

- 零依赖、零构建、可离线，`file://` 双击即玩
- 手机（触屏）与电脑（鼠标）双端适配

## 运行方式

**电脑**：直接双击 `index.html`（推荐 Chrome / Edge）。

**手机**：起一个本地静态服务，手机浏览器打开：

```bash
# 在 D:\work1 目录下
python -m http.server 8080
# 手机访问 http://<电脑IP>:8080
```

> 所有代码在本地运行，不上传任何数据。

## 玩法

### 战场
8×10 格地图，上半场是对手（AI）、下半场是你，中央山脊分隔。每一方各有一条 **S 形土路**：出怪口 → 蜿蜒土路 → 你的**守将（阿斗）**。

### 守将红心
阿斗有 **5 颗红心**。敌军沿土路冲向你的阿斗，漏过一个扣一颗，先掉光的一方落败。

### 征兵（整手重抽）
点「征兵」花馒头，**直接替换备战席为 5 张新卡**（士兵 / 武将汉字碎片 / 铲子）。同字同级士兵自动 2 合 1 升级（最高 5 级）。

### 布阵
点备战席卡牌 → 点亮起的**空地**放置。近战放贴路格、远程放后方。点「铲子」→ 点一块空地解锁新建造格（逐格解锁，开局有 ≥8 个设计好的初始地块）。

### 武将
征兵抽到金色**单字碎片**（赵/云/关/羽/张/飞/马/超/黄/忠/刘/备/曹/操…），拼齐姓名觉醒武将：
赵云·贯穿 / 关羽·横扫 / 张飞·眩晕 / 马超·重击 / 黄忠·超远速射 / 刘备·友军增伤 / 曹操·全屏斩…

### 模式
- **主线**：逐关守住 N 波，每波告破有馒头犒赏并给阿斗回心
- **无尽**：敌潮层层加码，看你能守到第几波
- **竞技**：与 AI 同受波次、各自防守，先失守者败；撑过 10 波即胜

### 其他系统
- 装备神兵：BOSS 掉落神兵自动配给武将
- 神秘商人：道具（神兵符/攻速符/毛笔/招贤令/农民/洛阳铲）
- 军衔星级、每日地图与 buff 轮换、离线挂机领金币

## 项目结构

```
index.html          入口
css/base.css        重置 / 水墨变量 / 响应式骨架
css/ui.css          菜单 / 备战席 / 商店 / 弹窗
css/battle.css      战场 HUD / 红心 / 底部操作区
js/config.js        数值配置（兵种 / 经济 / 波次 / AI 难度）
js/data.js          数据表（地图路径 / 兵种 / 武将 / 敌人 / 武器 / 道具）
js/utils.js         工具 + 合成音
js/save.js          localStorage 存档 / 迁移 / 离线
js/effects.js       水墨粒子 / 飘字
js/render.js        canvas 战场渲染（土路 / 建造格 / 守将 / 塔 / 敌人）
js/state.js         中心状态 + 玩法动作（征兵 / 部署 / 铲子 / 合成 / 结算）
js/battle.js        战斗引擎（敌人寻径 / 塔索敌 / 弹道 / 武将技 / 波次 / 红心）
js/ai.js            竞技 AI 对手
js/ui.js            屏幕路由 / HUD / 弹窗
js/main.js          启动器 + 主循环
```

## 平衡说明
数值集中在 `js/config.js`（征兵费用、波次构成、敌人成长、AI 难度）与 `js/data.js`（兵种/武将/敌人基础值）。想改难度直接调这两处。地图布局与建造格在 `js/data.js` 的 `MAPS` 里，可仿照现有 `pPath`/`pBuild` 自行设计新地图。

## 已知取舍
- 武将采用「手牌拼字成武将牌 → 上阵」单格方式（参考版的"相邻双半身"未采用）
- 主动道具购买后带进对局使用（最多 2 格）；「农民」为永久增益
- 离线奖励上限 8 小时
- 竞技 AI 为规则型对手（合牌/布阵/征兵），强度低于真人玩家

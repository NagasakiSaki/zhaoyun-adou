# 赵云与阿斗 · HTML 同款

一款纯前端实现的三国题材**汉字水墨塔防**小游戏，玩法还原抖音爆款《赵云与阿斗》：守卫阿斗、征兵合成、武将字牌召唤、装备道具、主线/无尽/竞技三模式、每日地图轮换与离线挂机。

- 零依赖、零构建、可离线，`file://` 双击即玩
- 手机（触屏）与电脑（鼠标）双端适配

## 运行方式

**电脑**：直接双击 `index.html`（推荐 Chrome / Edge）。

**手机**：把整个 `work1` 文件夹放到同一网络环境，起一个本地静态服务，手机浏览器打开：

```bash
# 在 D:\work1 目录下
python -m http.server 8080
# 手机访问 http://<电脑IP>:8080
```

> 所有代码在本地运行，不上传任何数据。

## 玩法速览

| 操作 | 说明 |
|---|---|
| 征兵 | 花「馒头」抽兵种 / 汉字 / 铲子，费用随次数上涨 |
| 合成 | 兵营中两个相同兵种同等级自动升阶：白→绿→蓝→紫→金 |
| 武将 | 集齐汉字（如「赵+云」）合成武将，自动释放技能（赵云贯穿、关羽横扫、张飞怒吼、黄忠全屏、刘备回血…） |
| 布阵 | 点兵营槽位 → 战场高亮格放置；近战放前、弓兵放后；铲子/洛阳铲向上解锁更多行 |
| 守卫 | 敌方进攻我方阿斗，阿斗血量为 0 即败 |
| 装备 | 胜利掉落神兵，自动配给对应武将（枪/刀/弓/骑） |
| 道具 | 神秘商人用金币购买：神兵符（升级+无敌）、攻速符、毛笔（改字）、招贤令、农民（+馒头/波） |

### 模式
- **主线**：逐关推进，守完 3 波即胜，获得金币/经验/星级/武器
- **无尽**：敌潮层层加码，坚持最远波数
- **竞技**：1v1 对阵 AI，率先打爆敌方阿斗者胜（阿斗血量更高，考验持续输出）

### 系统
- 军衔星级：胜利累积星级晋升军衔、解锁头像
- 每日轮换：地图与 buff 每日更换，商人货品每日刷新
- 离线挂机：离线自动积累金币，上线领取

## 项目结构

```
index.html          入口
css/base.css        重置 / 水墨变量 / 响应式骨架
css/ui.css          菜单 / 兵营 / 商店 / 弹窗
css/battle.css      战场 HUD / 血条 / 底部操作区
js/config.js        数值常量（费用曲线 / 掉落 / 平衡）
js/data.js          数据表（兵种 / 武将 / 敌人 / 武器 / 道具 / 地图）
js/utils.js         工具 + 合成音
js/save.js          localStorage 存档 / 迁移 / 离线
js/effects.js       水墨粒子 / 飘字
js/render.js        canvas 战场渲染
js/state.js         中心状态 + 全部玩法动作
js/battle.js        战斗引擎（网格 / 固定步长 / 波次 / 技能）
js/ai.js            竞技 AI 对手
js/ui.js            屏幕路由 / HUD / 弹窗
js/main.js          启动器 + 主循环
```

## 平衡说明
数值集中在 `js/config.js` 与 `js/data.js`（征兵费用、敌方血量成长、波次构成、竞技 AI 强度等），想改难度直接调这两处即可。第 1 关为参考基准：按「征兵→合成→布阵」正常发育约 40 秒内可通关。

## 已知取舍
- 主动道具购买后带进对局使用（最多 2 格）；「农民」为永久增益
- 离线奖励上限 8 小时
- 竞技 AI 为规则型对手（前排坦克 / 后排弓），强度低于真人玩家

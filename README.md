# 赵云与阿斗 · HTML 同款

一款纯前端实现的三国题材**汉字水墨·路径塔防**小游戏，玩法对齐抖音爆款《赵云与阿斗》并参考同类型《悟空与唐僧》的战斗模型：8×10 镜像战场、S 形土路、守将红心、整手征兵、**拖拽上阵**、**碎片相邻拼字觉醒武将**、金手指自定义。

- 零依赖、零构建、可离线，`file://` 双击即玩
- 手机（触屏）与电脑（鼠标）双端适配

## 运行方式

**电脑**：直接双击 `index.html`（推荐 Chrome / Edge）。

**手机**：起一个本地静态服务，手机浏览器打开：

```bash
# 在 D:\work1 目录下
python -m http.server 8080
# 手机访问 http://<电脑IP>:8080
```

> 所有代码在本地运行，不上传任何数据。

## 玩法

### 战场
9×14 格地图，上半场是对手（AI）、下半场是你，中央山脊分隔。每一方各有一条更长的 **S 形土路**：出怪口 → 蜿蜒土路 → 你的**守将（阿斗）**。开局每个半场有 ≥14 个建造格，其余为空地可用铲子逐格解锁。

### 守将红心
阿斗有 **5 颗红心**。敌军沿土路冲向你的阿斗，漏过一个扣一颗，先掉光的一方落败。

### 征兵（整手重抽）
点「征兵」花馒头，**直接替换备战席为 5 张新卡**（士兵 / 武将汉字碎片 / 铲子）。同字同级士兵自动 2 合 1 升级（最高 5 级）。

### 拖拽上阵
从备战席**拖**卡牌到亮起的空地上阵；拖到已有单位上可同字同级合成升级 / 换位；拖到备战席可回手 / 合成。点备战席卡牌也可查看攻击范围。

### 武将觉醒（自由组合）
征兵抽到金色**单字碎片**。把两个碎片放到**相邻**的建造格（**首字在左、尾字在右**）即可觉醒对应武将——三国名将自由组合：**赵+云=赵云**、**关+羽=关羽**、**张+辽=张辽**、**吕+布=吕布**、**周+瑜=周瑜**、**孙+策=孙策**、**姜+维=姜维**……共 **29 名**武将。拖同字碎片到武将军上可升级（最高 5 级）。

武将技能：贯穿 / 横扫 / 眩晕 / 重击 / 超远速射 / 友军增伤 / 全屏斩 / 范围减速。

> **上阵门禁**：初始只拥有 刘备/关羽/张飞；其他武将需通过**招募**解锁才能拼字上阵（未拥有的碎片纯占格，促使你抽卡）。

### 武将经验
武将在战斗中击杀敌人积累经验，杀敌达到阈值**自动晋级**（最高 5 级），武将牌下有经验条。

### 局外抽卡 & 升星（命座）
- 主页「**招募**」用**元宝**抽卡（单抽/十连），按稀有度权重抽 29 名三国武将。
- 初始只拥有 刘备/关羽/张飞；抽到**新武将**解锁，抽到**重复** → 仓库**信物**。
- 「**武将**」界面可升星（消耗信物）：每星 +15% 伤害，**C2/C4/C6** 解锁特性（伤害/射程/终极强化）。
- 元宝来源：关卡通关、每波/BOSS、每日任务、成就、首通奖励。

### 兵种训练
主页「**训练**」用金币升级 刀/枪/弓/骑，每级该兵种伤害 +10%。

### 每日 & 成就
主页「**每日**」领取每日任务（通关/杀敌/招募/训练）与成就奖励（元宝+金币）。

### 模式
- **主线**：逐关守住 N 波，每波告破有馒头犒赏并给阿斗回心
- **无尽**：敌潮层层加码，看你能守到第几波
- **竞技**：与 AI 同受波次、各自防守，先失守者败；撑过 10 波即胜

### 金手指
主页点「**金手指**」打开单机自定义面板，可随时调整：
- **资源**：开局馒头、金币（+1000）
- **抽卡**：士兵/碎片/铲子权重、新抽士兵等级、征兵免费
- **装备**：一键武将全满配神兵、满级满军衔
- **挂机**：离线金币速度倍率
- **难度**：己方伤害倍率、敌方血量倍率、阿斗红心、波次馒头倍率

### 其他系统
- 装备神兵：BOSS 掉落神兵自动配给武将
- 神秘商人：道具（神兵符/攻速符/毛笔/招贤令/农民/洛阳铲）
- 军衔星级、每日地图与 buff 轮换、离线挂机领金币

## 项目结构

```
index.html          入口
css/base.css        重置 / 水墨变量 / 响应式骨架
css/ui.css          菜单 / 备战席 / 商店 / 金手指 / 弹窗
css/battle.css      战场 HUD / 红心 / 底部操作区
js/config.js        数值配置（兵种 / 经济 / 波次 / 金手指默认 / AI 难度）
js/data.js          数据表（地图路径 / 兵种 / 29 武将 / 敌人 / 武器 / 道具）
js/utils.js         工具 + 合成音
js/save.js          localStorage 存档 / 迁移 / 离线
js/cheat.js         金手指（资源/抽卡/装备/挂机/难度覆盖）
js/effects.js       水墨粒子 / 飘字
js/render.js        canvas 战场渲染（土路 / 建造格 / 守将 / 塔 / 半身武将 / 敌人）
js/state.js         中心状态 + 玩法动作（拖拽 / 征兵 / 铲子 / 觉醒 / 结算）
js/battle.js        战斗引擎（敌人寻径 / 塔索敌 / 弹道 / 武将技 / 波次 / 红心）
js/ai.js            竞技 AI 对手
js/ui.js            屏幕路由 / 拖拽 / HUD / 弹窗
js/main.js          启动器 + 主循环
```

## 平衡说明
数值集中在 `js/config.js`（征兵费用、波次构成、敌人成长、金手指默认、AI 难度）与 `js/data.js`（兵种/武将/敌人基础值）。想改难度直接调这两处，或直接在游戏里用金手指调。地图布局与建造格在 `js/data.js` 的 `MAPS` 里，可仿照 `pPath`/`pBuild` 自行设计新地图；武将配方在 `HEROES` 里（`recipe` 首字/尾字）。

## 已知取舍
- 竞技 AI 为规则型对手（士兵上阵/合并/征兵），不主动拼武将，强度低于真人
- 主动道具购买后带进对局使用（最多 2 格）；「农民」为永久增益
- 离线奖励上限 8 小时（可用金手指加速）
